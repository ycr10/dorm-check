# 实施与验收计划

日期：2026-10-29。

## 本轮范围

继续现有“归寝”实现，完成 V2 定义的单班首版。保留原生 HTML/CSS/JavaScript 前端、PHP 后端；SQLite 用于隔离的本地验收，MySQL 用于正式部署。只使用虚构测试数据；不导入真实名单、不部署公网、不配置外部通知。

1. 补齐数据库、名单与授权、任务冻结、初报/补报/更正及版本控制。
2. 接通 API、CLI 初始化、本地路由与现有页面。
3. 完成日报、六工作表 XLSX、计划任务、运行信息、备份恢复与保留清理。
4. 验证权限、时间边界、会话、去重和冲突等场景；根据实际结果更新使用及部署文档。

## 明确的实现取舍

- 名单导入接受 UTF-8 CSV，最多 2 MB、1,000 条。现有 Excel 名单需要先另存为 CSV；不宣称支持 XLSX 上传。
- 沿用本地 OOXML XLSX 写入器，不引入 PhpSpreadsheet。这与 V2 的库选型不同，但六张表、文本标识符、防公式注入、一致性快照的验收要求不变。检查生成文件中的 XML 和工作表关系；未在真实 Excel 中验证的兼容性必须明示。
- 沿用基于 PHP HMAC 的 RFC 6238 TOTP，不宣称使用第三方认证库；以 RFC 测试向量验证算法，另测重放限制、恢复码和受限重新绑定流程。密码及加密仍使用 PHP 原生 Argon2id、AES-256-GCM，不降级为测试专用弱算法。
- GET 业务接口不隐式建任务或保存报表。每分钟 CLI tick 负责调度；提交操作仍在服务端检查开放时间并完成必要冻结，不能通过手机时间或漏跑 cron 绕过规则。
- 漏跑后的首次日报使用真实生成时点，明确标注延迟；不把后来数据冒充为 22:35 已知情况。
- 导入为明确的新增/更新，不因某人未出现在本次 CSV 中自动删除。换寝有生效记录，已冻结名册只能通过带理由的调整操作改变。

## 环境与证据

- 原目录只有部分 PHP 基础代码，业务层、API、CLI 和测试尚缺失。
- 初始 PATH 无 PHP/MySQL；已有 PHP WASM 8.5.10 没有 Argon2id，不能代替完整认证验收。
- 用户已允许在 work 下下载经官方校验的 Windows 便携 PHP，不修改系统 PATH、不安装服务。
- 最终验收记录只记实际执行结果。PHP、MySQL、浏览器、Excel 等没有执行的检查分别列为未验证，不根据设计推定通过。

## 本轮实施结果

数据库、业务层、日报、API、CLI、本地路由、备份恢复及测试均已补齐，并与现有前端接通。最后修复包括迟报初报／当前去向分离、冻结时重新核实负责人及请假快照、转寝历史隐私范围、初报后补列成员更正、空范围结项、旧晚任务交接、显式移出当前名册、Unicode 密码前端计数和账户失败渐进退避。

实际执行：PHP WASM／SQLite 42 项通过、13 个 PHP 文件语法解析通过；真实 HTTP 10 项通过；Edge 浏览器联调 14 项通过，已实际查看桌面／手机及明暗主题截图。完整结果、证据与复现说明见[验收记录](验收记录.md)。

原生 PHP 官方下载因连接失败未完成，没有改 PATH、安装服务或创建实际运行配置。缺少 Argon2id 的 WASM 只用于隔离验证；没有降低密码算法、加 HTTP 测试时钟或开放调试身份后门。原生密码认证、CLI、MySQL、正式 Web 栈、计划任务和真实 Excel 仍待目标环境验收。原稿中的具体安全公告与下载摘要本轮无法复核，不将其写成新核验结论。
