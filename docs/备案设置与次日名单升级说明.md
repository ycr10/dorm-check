## 备案设置

管理员登录后，在“系统设置 → 网站备案信息”分别填写完整 ICP 备案号和公安备案号并保存。保存属于敏感设置，可能需要近期身份验证。公安备案号格式示例：`测试公网安备00000000000000号`，数字会用于构造公安查询链接。

两项保存在当前站点的数据库中，不写入源代码；新安装默认留空，清空即可隐藏。后台、登录页和便捷登记页均读取只含这两项的公开接口，公安图标仍使用本地文件。**旧版写在 HTML 中的号码不会自动导入数据库**：升级前请准备好备案信息，在受控维护时段上传代码，立即登录后台填写并检查三处页脚。留空、JavaScript 禁用或接口失败时不显示，运营者应自行核对页面、号码、备案主体、域名和官方平台生成的链接及图标。

## 次日名单为何可能为空

已有名单记录和每天的查寝任务是不同数据。旧版管理页面只读任务，依赖服务器 `tick` 计划任务提前创建当天任务；若计划任务未配置、失败或晚于页面访问，当天页面可能为空，却提示导入名单。页面若跨午夜长期打开，所选日期也可能仍是上一天。这些是代码中可复现的情况，**不代表已确认现场问题的唯一原因**。

现在已登录用户打开默认日期的总览、我的查寝、跟进或日报时，页面调用有鉴权的 `prepare_today`：08:00 起补建或刷新当日未冻结任务，08:00 前只补准备已存在的前一晚任务，不凭空创建缺失的历史任务；不会改写已冻结的夜间名单或替代自动日报。默认日期随服务器业务日期切换，手动选择的历史日期保留。以前已存在的名单一般无需重新上传；若仍为空，应核对当前日期、名册是否有效、寝室授权、任务暂停状态和服务器计划任务日志。便捷入口同样在 00:00–07:59:59 默认显示前一晚，08:00 起显示当天。

网页补建只是兜底：浏览器关闭时不能持续调度，也不能生成自动首报。**仍须保留每分钟 `tick` 计划任务**。若旧任务已经冻结为空、名单此前并未成功保存、授权缺失或数据库／时钟有问题，不能保证本次自动修复；不要反复导入或清库，请先备份并诊断。历史日报不会被这次补建静默重写。

## 上传到宝塔

项目根为 `outputs/dorm-check/`；假设服务器根为 `/www/wwwroot/dorm-check/`，请按自己实际路径对应上传。先备份本站代码与数据库到非公开目录，在维护时段替换，保持正确的文件权限。

相对于上一轮便捷登记版本，需上传：

```text
src/Domain.php
src/bootstrap.php
public/api/index.php
public/index.html
public/quick.html
public/assets/app.js
public/assets/enhancements.css
public/assets/filing.js              （新增）
```

如果上轮便捷登记文件未全部上传，还需上传 `public/assets/quick.js`、`public/assets/quick.css`、`public/assets/police-filing.png`。如果不确定此前单账号两步验证和 MySQL 兼容修复是否已上传，也一起上传 `src/Auth.php`、`src/Schema.php` 和 `bin/console.php`。不要覆盖现有 `config/local.php`、`config/db-password.php`、`storage/` 或数据库；不需要重新初始化、清库或迁移表。不改共享 PHP／Nginx 配置，也不重启其他网站。

上传后按需由维护人员在受控窗口处理本项目的 PHP OPcache；不要为此擅自重启共享 PHP。Ctrl+F5 后填写备案，检查登录页、后台、`/quick.html` 和链接。先在隔离实例以虚构名单验证次日无计划任务时的兜底，再检查正式站的计划任务执行记录；不要用正式名单随意测试提交或覆盖历史。
