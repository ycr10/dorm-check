# 安全、PHP 运行时与核验边界

更新：2026-10-29。

## 1. 官方信息的核验状态

本轮无法直连 PHP 官方下载清单、发布站点及相关公告页面，也没有下载或安装原生 PHP。因此，**没有完成本轮官方公告复核、Windows ZIP 下载及 SHA-256 校验**。

原稿包含具体 CVE、发布日期、Windows 重建包和摘要值；本轮无法独立确认，已不将这些内容作为经过验证的下载依据。请部署人员从以下官方入口重新取得当前公告、受支持版本、包名及校验值：

- [PHP 官方首页与发布消息](https://www.php.net/)
- [官方支持周期](https://www.php.net/supported-versions.php)
- [Windows 官方下载页](https://windows.php.net/download/)
- [Windows 官方发布清单](https://downloads.php.net/~windows/releases/releases.json)
- [PHP 源码安全公告](https://github.com/php/php-src/security/advisories)

源码继承的生产版本门槛为 PHP 8.4.27 或 PHP 8.5.12 起（见 `Security::versionSafe()`），**这是当前程序的预设门槛，不是本轮重新核实的官方安全结论**。上线前既要满足门槛，也要根据当时官方信息安装受支持且已修补的版本；不能只通过版本比较就认定安全。不要为迁就旧运行时删除检查。若官方信息与预设门槛不符，应先完成有证据的版本策略修订及回归，再部署。

Windows 如有同版本重建包，运行时版本号可能不能区分包修订；须另外核对官方 ZIP 名称和 SHA-256。不要使用本文旧稿中的摘要或未知镜像。

## 2. 生产运行配置

- 使用支持原生 Argon2id 的 PHP，启用 PDO、PDO MySQL／PDO SQLite、OpenSSL、mbstring、ZipArchive、XMLWriter。
- 将 `deploy/php-production.ini` 放入实际 CLI 和 PHP-FPM 的启动配置目录，分别核实。`php --ini` 只能证明 CLI 配置，不能证明 FPM 配置。
- 启动时关闭 `session.upload_progress.enabled`，重启全部 worker；不依赖业务代码中的临时设置。
- 正式环境只使用 HTTPS，校准服务器时钟；Cookie 为 Secure、HttpOnly、SameSite，Session 在服务端保存。
- 网站根目录只公开 `public/`。仅 `/api/index.php` 进入 PHP-FPM，其他 PHP 路径返回 404；配置、备份、数据库、会话、日志和测试目录不可公开。
- 源码由维护账号管理，Web 账号只写运行数据目录；不用 `chmod 777`，数据库及 FPM 不对公网开放。

以上是配置要求，不代表本机已经安装或验证 Nginx、PHP-FPM、HTTPS、MySQL 和计划任务。

## 3. 应用保护边界

- 学号只是用户名。后台账号激活须由管理员核实后单独发放一次性凭据；没有默认密码或公开注册。宿舍负责人没有独立登录角色；班委只可查看和管理获授权班级的数据。
- 按用户需求新增的 `quick.html` 是**刻意不验证身份的例外**：学号＋寝室号匹配当晚寝室，但任何知道这两个信息的人都能冒充负责人查看本寝最低限度的人员信息并提交／更新。跨班混住时便捷入口返回整寝成员；后台班级隔离不等于便捷入口身份认证。记录标记“未验证身份”，不能当作本人操作证据。入口有同源、CSRF、每 IP 限流和任务范围约束，但这些不是身份验证，也不能阻止知情者冒充；后台账号和管理接口仍鉴权。
- 密码使用 PHP 原生 Argon2id，不因测试环境缺少算法而降级。管理员可按学号指定唯一 TOTP 账号；未设置时兼容旧的管理账号强制规则。密钥加密保存，恢复码仅存哈希并单次使用。
- 已登录业务请求重新检查账号状态、角色、当前授权和会话版本；历史负责人快照不赋予当前权限。授权撤销后旧会话不能继续操作；**这一保护不适用于无身份验证的便捷入口**。
- 写请求检查方法、JSON 格式、大小、同源及 CSRF；服务端不采信客户端角色、操作者或测试时间。
- 便捷初报整寝原子保存，班委后台按授权范围原子保存；补报、更正、原始事实及当前状态分开。乐观版本控制和去重键防止静默覆盖。
- 业务 SQL 参数化，用户内容按文本呈现，配合 CSP。导出强制文本单元格，避免将学号、姓名、备注解释成公式。
- 导出经鉴权流式下载，临时文件在私有目录并清理；文件下载后不再受网站撤权控制。
- 审计不记录密码、激活码原文、动态码或会话令牌。审计可追溯，但不承诺抵御服务器或数据库最高权限的篡改。

## 4. 数据、备份与恢复

仅收集确认返寝所需信息，不收集指纹、精确定位、详细病情或证明照片。正式名单不得进入公开仓库或公开反馈。

备份采用自定义 v2 `.dcb` 分块 AES-256-GCM 格式，独立 `DORM_BACKUP_KEY` 离线保管。它不是普通 ZIP，不能用解压工具代替受控恢复。归档带应用加密密钥，敏感程度与数据库相同。文件及展开数据有 512 MiB 上限；更大数据需另行设计备份流程。

恢复必须在维护模式中执行。成功恢复会撤销密码、会话、一次性码、TOTP、恢复码和旧授权；核实人员、重发重置码、重新绑定管理验证器、检查数据缺口后，才能明确确认解除维护。配置不会自动覆盖。完整步骤见[部署教程](部署教程.md)。

## 5. 本轮证据与未验证事项

年级版实际结果见[全年级升级说明](全年级升级说明.md)。隔离 SQLite、TOTP 测试向量、备份恢复、真实 HTTP 与预认证虚构会话的浏览器流程各自只证明其列明范围。

PHP WASM 8.5.10 缺少 Argon2id，**不能证明成功激活、密码登录或密码重置，也不能用作生产 PHP**。原生 CLI、MySQL、真正多进程并发、Nginx/PHP-FPM/HTTPS、系统 cron、官方下载校验及真实 Excel 打开兼容性仍需在目标环境验收。

初报是填报信息，不自动证明人员实际位置；便捷入口的初报也不证明实际填报人的身份。“确认安全”不等于“已在寝”。本版没有微信／QQ 群推送，也不保证网页关闭后的提醒到达。PHP 内置服务器和本地 WASM 适配器均不得面向公网。
