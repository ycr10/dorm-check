# 便捷登记与备案信息：升级说明

> 本页主要记录上一轮便捷登记升级；最新版日期规则、筛选及上传清单，以[日期切换与筛选升级说明](日期切换与筛选升级说明.md)为准。

本轮按需求新增免登录寝室登记、一键全到、可选 Cookie 记住学号／寝室号，并在登录、后台和新页面展示 ICP 与公安备案信息。代码在本地 `outputs/dorm-check/`；**没有连接、上传或修改用户服务器，也未导入真实名单。**

## 一、先理解免登录的风险

学号与房号不是秘密，也不是有效的身份凭据。任何知道这两个信息的人，都可能冒充寝室长查看该寝当晚的姓名／状态、提交初报或修改当前状态；旧的登录权限撤销不能阻止这种冒用。即使有 Cookie、CSRF、同源限制和频率限制，**也不能证明填报人是谁**。

这是按用户明确需求提供的低门槛入口，管理员应确认班级能够接受误报、冒报和个人信息暴露风险，必要时选择只在可信内网开放或继续使用原登录登记。只靠事后审计无法证明真实操作者。

技术上尽量缩小范围：

- 只匹配当前有效学生名单中的寝室负责人、所填房号和当晚任务，不建立登录态，也不能访问后台、跨寝记录、任意历史或全班名单。
- 响应仅含该寝登记必要姓名、状态和版本，不返回其他人的学号、请假详情或联系方式。
- 写入沿用服务端查寝时点、冻结名册、完整初报、版本冲突、幂等、必要去向和请假核实规则；不得指定自己的系统角色、日期、时间或其他任务 ID。
- 操作记录为 `quick_initial`／`quick_update`，`actor_id=null`、`identity_verified=false`，同时记录**自称**的学号，不伪装为已登录本人。
- 查询与提交按服务器看到的 IP 各限制每 5 分钟 60 次，同源、CSRF 和维护模式正常生效。NAT 或反向代理下可能共用同一个额度；配置可信代理时应由服务器维护人员处理真实客户端 IP，不能信任任意伪造的转发头。

## 二、使用方法

直接打开：

```text
https://dorm.example.com/quick.html
```

或从首页“寝室长便捷登记”进入（上述为示例地址，部署时替换域名）。输入名单里寝室长的完整学号和房间号（不用楼栋，保留前导零）。匹配不到、负责人不在当前寝室、名单没有导入，或不能唯一确定时请联系班委核实。

进入后逐人确认，点击“一键全到”只为可编辑人员填入“已在寝”，不会立即提交；人工核实、勾选确认，再点提交。已有不可覆盖的转寝原始记录不会被批量修改。若有不在寝人员，应选择相应状态并填写已知情况。初报之后可以逐人更新当前状态；历史原始初报保留。

迟报时若某人查寝后才回寝或更换去向，应展开该人员下面的“迟报时情况已变化？填写当前状态”，把查寝时状态与当前状态分开填写；变化发生时间选填，未知时以服务器接收时间为准。

日期按服务器北京时间计算：**00:00–07:59:59 显示前一晚，08:00 起显示当天**。前一晚不存在时不会伪造创建。尚未开放、已暂停或结项的任务不能提交；更早的未结事项、原始更正或代理交接仍用已登录入口。

## 三、Cookie 说明

“在这台设备的浏览器记住学号和寝室号”默认不勾选。用户主动勾选后，只保存填写的学号与房号到本机 Cookie，最长 30 天；不保存密码、完整名单或申报内容。Cookie 采用 `SameSite=Strict`，HTTPS 下 `Secure`，路径限制到 `quick.html`；脚本需要读它，因此不是 HttpOnly，也不是登录凭证。可以点“清除已记住的信息”或取消勾选；公用设备不要保存。已知网络访问没有同时改变这些身份风险。

## 四、备案号及图标

公开源码默认不包含运营者备案号。管理员登录后进入“系统设置 → 网站备案信息”，分别填写完整的 ICP 和公安备案号；清空后不显示。所有页面通过同域只读接口读取这两个公开字段，公安查询链接从备案号中的数字生成，公安图标本地托管。

更新此版本后，旧代码中写死的备案信息不会自动迁移；上线前必须先在后台填写并确认三个页面的显示和链接。无 JavaScript、接口不可用或空配置时页脚不会显示，运营者应检查自身部署是否满足要求。

公安图标本地文件：`public/assets/police-filing.png`，从公安备案历史官方站点 `https://www.beian.gov.cn/img/new/gongan.png` 取得，已查看并本地托管，不需要外部图片 CDN。链接在新标签打开并使用 `noopener noreferrer`；如果站点设置 CSP，请保留允许本域图片的 `img-src 'self'`。

按[工信部门办事指南](https://hljca.miit.gov.cn/bsfw/bszn/art/2023/art_432d08d3362c48d8904ce25923419d72.html)，备案号应在首页底部显示并链接工信部查询页面；[深圳公安指引](https://ga.sz.gov.cn/ZT/HLWSYSQ/CJWT/content/post_10705416.html)说明可从已备案网站的详情获取图标与代码。请运营者在备案平台核对号码、主体、域名关联以及官方生成的链接与图标。此实现不构成已满足所有备案、隐私或个人信息处理法律要求的承诺。

## 六、上传后的核对

1. 按上表完整替换代码，恢复本项目站点及其计划任务；**不需要修改共享 PHP 全局配置或更改其他网站**。
2. 新页面脚本带版本号以避免浏览器复用旧缓存；如共享 FPM 的 OPcache 不自动更新 PHP 文件，需由维护人员采用受控方法更新本项目代码缓存，不无计划重启共享 PHP。
3. 浏览器 Ctrl+F5 打开首页和 `/quick.html`，确认页面、两条备案号、公安图标和查询链接可用；核对管理登录仍然正常。
4. 在**隔离测试实例**使用虚构名单，核验正确及错误学号／房号、一键全到、非全到、迟报分开填写、返寝更新、Cookie 保存与清除，以及匿名访问后台被拒绝。不要为测试随意覆盖正式查寝记录。
5. 班级负责人核对风险、真实名单关系、备案主体与链接后再交付使用。登录身份相关风险、学校制度和个人信息处理要求由实际运营方继续核实。
