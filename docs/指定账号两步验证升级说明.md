# 指定账号两步验证：升级与上传说明

本次需求：后台通过登录学号指定唯一的两步验证账号，只保留该账号的验证器绑定，取消班长及其他账号的强制两步验证。

**本地实现和隔离验收已完成；尚未连接或修改你的服务器。不要清空数据库，也不要重新执行 init。**

## 一、修改后的规则

- 系统设置新增“**两步验证账号**”，仅系统管理员可保存。
- 填写一个已激活、未停用的完整登录学号；保留前导零，不能留空，不是填写姓名或单纯名单中的人员编号。
- 保存后只有这个学号要求且允许绑定 TOTP。该账号已绑定时，原密钥和恢复码保留；未绑定时，必须由本人在登录后完成绑定，后台不会假装已经绑定成功。
- 其他班长、班委、管理员和寝室长的 TOTP 密钥及绑定会清除，旧恢复码作废；之后用学号＋密码登录，个人页面不提供绑定入口，后端也拒绝其绑定请求。
- 修改策略会使**所有账号的旧登录会话失效，包括当前管理员**。这是安全切换，不是保存失败。
- 账号角色、密码、寝室授权、名单和历史查寝数据不改变。
- 只保存其他日常设置，或者再次保存同一学号，不会重复解除绑定或注销会话。

### 首次保存之前

升级不自动猜测哪个账号是你。尚未保存指定学号时，仍沿用旧规则：班委、管理员强制绑定，普通寝室长不强制。页面会明确显示“尚未配置”。你保存本人学号后，才切换为单账号规则。

### 密码规则

本轮没有修改密码长度，仍为 15–64 个字符；不包含此前讨论但未最终实施的六字符密码调整。

## 三、宝塔实际操作顺序

前提是现有数据库已经完成初始化，且你知道自己管理员账号的密码并持有有效验证器／恢复方式。

1. 在宝塔备份本项目数据库及上述将替换的源码文件，备份放在公开目录之外。私有配置和应用密钥也应安全保存。
2. 暂停**查寝本站**和它自己的 tick 计划任务，在维护时段完成文件替换。不要停止其他网站或共享 MySQL／PHP 服务。
3. 按上传表替换完整文件，保留原有权限。不要只上传前端而遗漏 Auth／Domain，也不要把新旧后端混用。
4. 本功能使用已有 `settings` 表保存新键，**不需要删库、建表迁移或重新 init**。
5. 确认 PHP 实际加载了更新后的代码。若共享 FPM 的 OPcache 不自动检查代码更新，由维护人员采用受控方式处理本项目的缓存；不要公开重置接口，也不要无计划重启共享 PHP 影响其他网站。
6. 恢复本站和原有计划任务。浏览器按 Ctrl+F5 刷新。新 HTML 的脚本地址应包含 `app.js?v=20261029-totp-account`。
7. 使用你自己的管理员账号登录。首次设置之前仍按旧规则验证，不会自动解除你的验证器。
8. 进入 **系统设置 → 两步验证账号**。该面板在每日查寝规则下面，需要向下滚动。
9. 在“启用两步验证的学号”中填写你本人的完整登录学号，点击“保存两步验证账号”。不要误填班长学号。
10. 阅读确认提示，确认后保存；如果要求近期验证，输入当前密码和新的动态码。已经使用过的动态码不能重复使用。
11. 保存成功会回到登录页。用你的密码＋验证器动态码重新登录。若你选中的账号原本未绑定，它会先被引导绑定。
12. 班长重新登录后只需学号和密码，“我的账号”显示“未指定此账号”，不会再强制绑定。

系统不会改变班长的业务角色和寝室权限：去掉的是两步验证，不是全班总览、核实、更正等业务权限。

## 四、检查清单

- [ ] 系统设置能看到“**两步验证账号**”面板。
- [ ] 保存的学号确实对应你的已激活登录账号，前导零正确。
- [ ] 填空值、不存在／未激活／停用账号时，设置被拒绝，原规则不变。
- [ ] 只有管理员可修改，班长／寝室长不能保存此设置。
- [ ] 真正变更需要确认和近期身份验证；保存之后所有旧会话失效。
- [ ] 你的原验证器仍可用，原恢复码没有被重新生成或删除。
- [ ] 班长无需动态码可重新登录，仍具备原角色业务权限。
- [ ] 非指定账号没有绑定入口，直接调用绑定接口也被拒绝。
- [ ] 保存一般规则／相同学号不会重复使会话失效。
- [ ] 在“操作记录”可见 `settings.totp_account` 审计，不包含验证器密钥或恢复码原文。

## 五、恢复与回滚注意

丢失指定账号的验证器时，使用密码＋恢复码恢复，仍需本人重新绑定。恢复码也丢失时，由服务器维护人员核实身份后，对**该指定学号**执行原有受控 `mfa:reset` 流程；不要临时改数据库关闭所有安全检查。

不要只回滚其中一个源码文件。回滚旧版后，旧版会再次要求班委／管理员绑定；已经解除的其他人的验证器需要重新绑定，不能假设上传旧代码会恢复已清除的密钥。数据库恢复须走完整维护和凭据核实流程，不能静默恢复旧身份凭据。
