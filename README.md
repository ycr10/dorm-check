# 归寝 · 年级晚查寝系统

一个年级共用一套系统，按班级导入名单、分配后台权限和查看日报。前端使用原生 HTML、CSS 和 JavaScript，后端使用 PHP；SQLite 用于隔离测试，MySQL 用于正式部署。生产运行无需 Node、Composer 或外部 CDN。

## 重要边界

- 系统管理员管理全年级与账号；班委只可查看和管理被授权班级的学生。冻结历史按当时班级归属保留。
- 宿舍负责人不再使用宿舍长账号。便捷登记按需求**不验证身份**：知道负责人学号和房号的人可能冒充填报，并查看同寝人员的最低限度信息。跨班混住时一次登记整寝；后台班委仍按班级隔离。
- 默认每天北京时间 22:30 查寝、22:35 初报截止；00:00–07:59:59 默认查看前一晚，08:00 起默认当天。手动选择日期只显示该日。
- 本轮只使用隔离环境和虚构数据，没有连接或修改用户服务器、数据库或共享 PHP/Nginx 配置。

## 已验证范围

- PHP WASM／SQLite：迁移后的原业务回归 **71 项通过**，年级专项 **19 项通过**，覆盖跨班混住、班级权限、历史日报、Excel、负责人交接、旧库映射和新版备份恢复。
- 隔离 HTTP 安全边界 **12 项通过**；Edge 流程 **10 项通过**，包括班级创建、导入、授权、越权拒绝、日期筛选和便捷登记。浏览器管理流程使用虚构预认证会话，跨日切换使用模拟服务器时间。
- **不等于生产验收通过：**WASM 不支持 Argon2id，成功密码激活、登录和重置未验证。原生 PHP CLI、MySQL、宝塔、Nginx／PHP-FPM、HTTPS、系统计划任务、多进程并发和真实 Excel 打开兼容性仍须在目标环境验收。

## 功能概览

- 管理员创建／更名班级、建立个人管理账号、分配和撤销班级权限；不设宿舍长登录角色。两步验证可按指定学号启用，备案号可在后台配置。
- 按班级预览导入 CSV；未出现在文件中的学生不自动删除。住宿关系保留生效历史，已冻结的旧晚记录不因日常导入改写。
- 便捷入口按当前宿舍负责人学号和房号识别宿舍；“一键全到”只填状态，仍须逐人核实并确认提交。提交和补报记录标记未验证身份。
- 班级／年级范围的任务、跟进、固定日报和六表 XLSX 导出；混住宿舍中的班委初报只影响其授权学生，涉及整寝的结项和名册调整须覆盖整寝范围。
- 初报、补报、更正、草稿、幂等键和版本冲突保护；`tick` 负责自然日调度和自动日报，网页打开不能代替计划任务。
- 私有加密备份和维护模式恢复；恢复新版备份后密码、会话、一次性凭据、TOTP 及班级授权均须按流程重建。旧单班备份需先用旧版源码恢复到隔离库，再核实并迁移。

## 本地运行与测试

在满足源码安全门槛并具有原生 Argon2id、PDO、OpenSSL、mbstring、ZipArchive 和 XMLWriter 的隔离环境中，可按部署教程使用空数据库初始化。`demo` 只允许空的 development 数据库，生成随机一次性激活码，不设置默认密码；不得用于生产。

本地验证入口：`php tests/run.php`、`php tests/grade.php`、`node --check public/assets/app.js`；隔离开发服务启动后可运行 `node tests/http.mjs`。仓库中的 PHP WASM 工具只用于本地验收，不可面向公网。

网站只公开 `public/`，配置、数据库、会话、日志、备份、测试和文档目录均保持私有。导出为 `.xlsx`，导入只支持 UTF-8 CSV。网站地址仍来自 `config/local.php` 的 `app_url`，或 `DORM_CONFIG` 指定的配置；本版没有后台自动切换域名功能。
