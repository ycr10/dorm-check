# 归寝 · 班级晚查寝系统

原生 HTML/CSS/JavaScript 前端、PHP 后端；SQLite 用于隔离本地验收，MySQL 路径用于正式部署。生产运行无需 Composer、npm 或外部 CDN。

默认每天北京时间 22:30 逐人登记，22:35 初报截止；班委可配置时间。后来返寝持续补报，原始初报、更正与当前状态分别留存。学号是用户名，个人密码及服务端授权控制访问。

## 主要功能

- 一次性激活／重置、Argon2id 密码、按指定学号启用 TOTP、恢复码与会话撤销；尚未配置指定学号时兼容原管理角色强制规则。
- 按当前授权控制寝室和任务访问；临时代报使用本人账号，旧晚交接须明确指定任务。
- 整寝原子初报、在线私有草稿、补报、更正、幂等重试、版本冲突、跨零点和完整时间线。
- 在寝、外出未归、获准无需返寝、待核实、未登记分开统计；确认安全不会自动变在寝。
- 班委总览、联系跟进、抽查、不可变日报版本、鉴权下载六工作表 XLSX。
- UTF-8 CSV 预览导入、住宿生效历史、显式移出名册、冻结快照调整和核实请假。
- CLI 调度、延迟补跑、运行状态、加密备份、受控恢复及显式保留清理。

## 运行入口

先取得经官方校验、满足源码门槛且支持 Argon2id 的原生 PHP，启用所需扩展并关闭 `session.upload_progress.enabled`。在本目录运行：

```text
php bin/console.php init --env=development --url=http://127.0.0.1:8765 --db=sqlite --class=虚构验收班
php bin/console.php doctor
php bin/console.php demo
php bin/console.php tick
php -S 127.0.0.1:8765 -t public public/router.php
```

`demo` 只允许空的 development 数据库；不要先建账号再运行。它产生随机一次性激活码，没有默认密码。以上为目标环境步骤，本机尚未原生执行。打开 `http://127.0.0.1:8765/`；详细配置、正式账号建立和生产部署请按教程操作，不能跳过环境检查。

本地回归：`php tests/run.php`、`node --check public/assets/app.js`；另启隔离开发服务后执行 `node tests/http.mjs`。Node 仅用于测试。

## 数据与使用范围

系统用于安全返寝确认，不做考核扣分或公开排名，不接入定位、人脸、指纹或自动群消息。CSV 导入不会因某人没出现在本次文件中而删除该同学；移出当前名册、撤销授权与停用账号是不同操作。

网站只公开 `public/`，配置、数据库、会话、日志和备份保持私有。导出是真正 `.xlsx`，但导入仅支持 CSV。当前沿用自写 RFC 6238 TOTP 与 OOXML 写入器，不宣称使用原 V2 指定的第三方库。正式名单、服务器、域名、证书与数据库均由部署人员核实配置；源码交付不表示已对公网发布。
